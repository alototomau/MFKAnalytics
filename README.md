# MFKAnalytics

Personal portfolio website for Mauricio Montoya Huertas / MFK Analytics.

## Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Vercel

## Deploy on Vercel

Framework preset: **Vite**  
Build command: `npm run build`  
Output directory: `dist`
