# MFKAnalytics

Personal portfolio website for Mauricio Montoya Huertas / MFK Analytics.

## Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Vercel

## Deploy on Vercel

Framework preset: **Vite**  
Build command: `npm run build`  
Output directory: `dist`

## SEO included

- Meta title and description
- Open Graph / Twitter metadata
- `robots.txt`
- `sitemap.xml`
- JSON-LD structured data
- Favicon and social preview image

## Important

The CV download button expects this file:

public/Mauricio_Montoya_Huertas_CV.pdf
